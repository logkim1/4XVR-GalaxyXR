# 4XVR for Galaxy XR

Quest용 4XVR 2.0.22를 갤럭시 XR에서 실행되도록 이식한 비공식 패치입니다.

갤럭시 XR에 최적화된 HDR 톤매핑을 탑재했고, 장시간 재생 시 메모리가 누적되던 문제를 해결했습니다.

원본에 없던 자막 위치 조절과 사용자 지정 자막 글꼴 기능 등 다양한 최적화가 적용되었습니다.

> 기본은 무료판이며, 갤럭시 XR에서 **Meta 계정 인증**을 거치도록 구현되었습니다. 구매 이력이 없다면 Meta 스토어에서 구매 후 이용하세요.

## 다운로드

[최신 릴리스](https://github.com/logkim1/4XVR-GalaxyXR/releases/latest)에서 `4XVR-2.0.22-GalaxyXR.apk`를 받으세요.

## 설치

1. 기존 4XVR이 설치되어 있다면 먼저 삭제합니다.
2. APK를 헤드셋에 복사한 뒤 파일 앱에서 열어 설치합니다.

## 설정

- 설정 → 4X 디스플레이 기술을 고급(기본값)으로 두면 갤럭시 XR에 최적화된 HDR 톤매핑이 적용됩니다.
- 4K HDR 영상은 실시간 톤매핑으로 GPU 부하가 큽니다. 고급으로 볼 때는 반드시 **공허**(극장 선택)를 사용하세요.
- 영상 설정은 기본값 기준으로 최적화되어 있습니다.
- 색상 보정은 순수 흰색으로 맞춰 주세요.
- 자막 글꼴은 `/sdcard/4XPlayer/fonts/`에 ttf 또는 otf 파일을 넣고 앱을 다시 실행하면 바뀝니다.
