# 4XVR for Galaxy XR

An unofficial patch that runs the Quest version of 4XVR 2.0.22 on Samsung Galaxy XR.

It adds HDR tone mapping tuned for the Galaxy XR display and fixes the memory buildup during long playback.

Various optimizations have been applied, including subtitle position controls and custom subtitle fonts not found in the original app.

> This is the free version by default, and it has been implemented to go through **Meta account verification** on Galaxy XR. If you have no purchase history, please purchase from the Meta Store before use.

## Download

Get `4XVR-2.0.22-GalaxyXR.apk` from the [latest release](https://github.com/logkim1/4XVR-GalaxyXR/releases/latest).

## Install

1. If 4XVR is already installed, uninstall it first.
2. Copy the APK to the headset and open it in the Files app to install.

## Settings

- Keep Settings → 4X Display Technique on Advance (the default) for HDR tone mapping tuned for Galaxy XR.
- Real-time tone mapping makes 4K HDR video GPU-heavy. On Advance, always watch it in **Void** (Theatre menu).
- Video settings work best at their defaults.
- Set Color Correction to pure white.
- To change the subtitle font, put a ttf or otf file in `/sdcard/4XPlayer/fonts/` and restart the app.
